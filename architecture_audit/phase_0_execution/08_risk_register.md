## 2. المخاطر التفصيلية

### R-01 · EC-0.2a قد يُفقد بيانات offline شرعية

| البُعد | التفصيل |
|---|---|
| **الخطورة** | HIGH |
| **الاحتمال** | مؤكد — كل استدعاء offline بعد التحديث يبدأ بكاش فارغ |
| **الأثر** | السائق في منطقة تغطية ضعيفة يرى شاشة فارغة بدل آخر سجل |
| **السبب** | `static → instance` + مفتاح مقيَّد بالسائق = تصفير ضمني |
| **التخفيف** | إبلاغ المستخدم بوضوح. الشاشة الحالية (`EldRetryView`) تتعامل مع `Left(NetworkFailure)` أصلاً |
| **المتبقي** | **مقبول** — correctness > convenience في نظام امتثال |

### R-02 · EC-0.2a قد يكون **غير كافٍ** وحده

| البُعد | التفصيل |
|---|---|
| **الخطورة** | HIGH |
| **الاحتمال** | متوسط |
| **الأثر** | بقاء مسار تسرّب |
| **السبب** | إذا وُجد **مصدر آخر** للبيانات خارج الكاش (مثلاً `LocalStorageService` يقرأ سجلات DOT محلياً) |
| **التحقق المطلوب** | ✅ **تم** — `grep` على `log_local_data_source` لا يُرجع DVIR؛ مستودع DVIR لا يكتب محلياً (يعدّل في Working Tree) |
| **المتبقي** | EC-0.2a + EC-0.2b كافيان لحقلَي الكاش |

### R-03 · قياس EC-0.2b على خط أساس متكسر

| البُعد | التفصيل |
|---|---|
| **الخطورة** | MEDIUM |
| **الاحتمال** | مؤكد |
| **الأثر** | **لا يمكن إثبات أن الإصلاح لم يُكسر شيئاً** — 7 اختبارات فاشلة أصلاً |
| **السبب** | `codriver_page_test.dart` فيه 7 إخفاقات سابقة |
| **التخفيف** | **فحص متعمَّد**: هل الفشل قبل وبعد متطابقان بالاسم والرسالة؟ يُسجَّل في العقد |
| **المتبقي** | يحتاج تقريراً منفصلاً عن سبب الـ 7 |

### R-04 · EC-0.1a قد يُفرط في التصحيح

| البُعد | التفصيل |
|---|---|

| **الاحتمال** | منخفض |
