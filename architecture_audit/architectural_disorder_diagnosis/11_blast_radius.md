# 11 — المخاطر ونطاق الانفجار (Risk & Blast Radius)

> "الأثر المعماري" ≠ "الأثر الإنتاجي الفوري". مصنّفان منفصلان لكل سبب.

## RC-A — تشتت DI

| البعد | التقييم |
|---|---|
| ملفات متأثرة | ~25 مزودات + كل مستهلكي `trackingService*` |
| ميزات | الكل (tracking حرج) |
| مركزية | `tracking_providers`، `backend_providers`، `app_providers` |
| أثر معماري | **عالٍ** — أي توحيد يمس كل الميزات |
| أثر إنتاجي فوري | **منخفض** — يعمل اليوم (مثالان يعملان) |
| انحدار محتمل | متوسط (ترتيب التهيئة) |
| صعوبة الاختبار | متوسطة (تحتاج `ProviderContainer` + overrides) |

## RC-B — نماذج بلا مالك

| البعد | التقييم |
|---|---|
| ملفات | ~20 (7+9 حواف + المستهلكون) |
| أثر معماري | **عالٍ** — نقل أي نموذج يكسر مستوردين في 3 طبقات |
| أثر إنتاجي | منخفض (يعمل) |
| انحدار | منخفض (نقل + re-export انتقالي) |

## RC-C — دورة التوجيه (25 ملفاً)

| البعد | التقييم |
|---|---|
| ملفات | 25 (17 صفحة + 5 توجيه + 3 ودجات) |
| أثر معماري | **حرج** — كسرها يمس كل شاشة |
| أثر إنتاجي للكسر | **صفر** (الدورة حميدة وقت التشغيل — Dart يتحملها) |
| انحدار الإصلاح | **عالٍ** (نقل `rootNavigatorKey` + تحديث 7 مستوردين) |
| صعوبة الاختبار | عالية حالياً (لا عزل) → منخفضة بعد الكسر |

## RC-D — سياج الجلسات الجزئي

| البعد | التقييم |
|---|---|
| ملفات | ~15 + 63 ملف تعديلات جارية |
| أثر إنتاجي | **حرج إيجابي** — يمنع تسرب بيانات بين سائقين (COD-001 المتبقي هو الخطر) |
| انحدار التوسعة | متوسط (سلوك offline يتغير) |

## RC-E — العرض كطبقة تطبيق

| البعد | التقييم |
|---|---|
| ملفات | ~60 (عناقيد HL/DST/CON) |
| أثر معماري | **عالٍ** — النقل لطبقة تطبيق يمس كل رحلة |
| أثر إنتاجي | منخفض (يعمل) |
| انحدار | **عالٍ** (تغيير سلوك حدودي FMCSA) |

## RC-F — شكل الـ wire الموزّع

| البعد | التقييم |
|---|---|
| أثر إنتاجي | **متوسط-عالٍ** — إخفاقات صامتة (mock فارغ، `values.first` سابقاً) |
| انحدار التوحيد | متوسط (تغيير شكل مقروء في أماكن متعددة) |

## RC-G — قناة الأخطاء النصية

| البعد | التقييم |
|---|---|
| أثر إنتاجي | **عالٍ (مُثبت)**: رفض خادم ⇒ يُطبَّق محلياً (اختبار فاشل) + رسائل مضللة (17 موقعاً) |
| انحدار الإصلاح | متوسط (تغيير ما يراه السائق) |

## RC-H — لا إنفاذ

| البعد | التقييم |
|---|---|
| أثر | مُمكِّن — كلفة الإصلاح ~0 (إضافة lint + تنظيف ميت) |
| انحدار | معدوم تقريباً |

## أخطر علاقة تبعية واحدة

`home_page ↔ driving_lock_screen` (استيراد متبادل مباشر): صفحة تستورد ودجت يستورد الصفحة من أجل مزود `developerBypass`. أي تغيير في أيهما يُعيد ترجمة الآخر — **والسبب مزود واحد في المكان الخطأ**. الإصلاح: نقل المزود لملف مستقل (سطر واحد يُلغي دورة).
