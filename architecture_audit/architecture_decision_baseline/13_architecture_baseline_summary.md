# 13 — خلاصة خط الأساس (Baseline Synthesis)

## 1. الوحدات ومسؤولياتها الفعلية

| الوحدة | الفعل |
|---|---|
| `app/` + `main` + `app.dart` | إقلاع + حاوية DI بتجاوزات + تنسيق عابر (تتبع/جلسة/سناك) |
| `backend/` | أوضح الوحدات حدوداً: 15 عقداً + محوّلان + Dio واحد + اختيار مركزي |
| `core/` | بنية حقيقية ~85% + 4 ملفات عابرة + ازدواجا (زمن/خطأ) + جذر DI ناقص |
| `domain/` + `core/domain/` | كيانات نظيفة عدا ملف Flutter واحد + جذر موازٍ غير مبرر |
| `features/` | 9 ثلاثية متفاوتة + 1 (عرض+تطبيق) + 5 عرضية منضبطة + connection المنسقة في الصفحة |
| `routes/` | توجيه مركزي الحراسة، دوري البنية (25 ملفاً) |

## 2. نقاط القوة الموثقة (12 — انظر 10)

أبرزها: محوّل الخلفية، عقود المستودعات، محرك HOS، Dio الواحد، الكيانات المميزة، تجاوزات Riverpod، حقبة الجلسة، تجريدات المزامنة.

## 3. الخروقات المؤكدة (12 — انظر 11)

أخطرها إنتاجياً: V-BND-10 (كاش codriver المتبقي) وV-BND-12 (تصنيف الرفض). أوسعها: V-BND-09 (الدورة). أعمقها: V-BND-04/05 (انقلاب `core`).

## 4. صراعات الملكية

الجلسة (3 آليات)، الهوية الرقمية (تحويل مبعثر)، القواعد (`core` يراقب العرض)، المركبة (كتابة عابرة + قاعدة ×3)، التتبع (مثالان)، الملاحة (بلا تجريد)، الأخطاء (بوابة صحيحة ملتَف حولها)، التعيين (مخططات ممتازة + تحليل مبعثر)، الإعدادات (تطبيع ×4).

## 5. مشاكل الاتجاه

7 (`core→features`) + 9 (`backend→features`) + 2 (عرض→تنفيذ) + 2 (مستودع→DTO) + 5 (كتابة عابرة) + دورة 25 + 3 ثنائية. مقابل ~1,650 حافة سليمة الاتجاه.

## 6. الاستثناءات المشروعة

استهلاك مزودات `data/providers` (نمط Riverpod)، `RawJson` (براغماتية ناقصة المخطط)، `SessionEpoch` العام (مبرر موثق)، `BackendRegistry` (ميت لا مخالف)، الميزات العرضية (انضباط)، `expectedOwnerDriverId` (أمان تكتيكي).

## 7. الافتراضات غير المتحققة (10 — انظر 12)

أحرجها: أجسام `logs/cycle` (F4)، مخطط FMCSA، إخفاقات codriver_page السبعة، endpoint التوكن (مُعيق موروث).

## 8. الأنماط المحفوظة

`guardedNetwork`، `Result`/`Either`+`fold`، `AppLogger` حصرياً، `AppLocalizations`، بنية المجلدات، `RouterNotifier`، `keepAlive`+`dispose`، `ref.onDispose` للموارد.

## 9. ما يحتاج تحقيقاً لاحقاً

U3 (codriver tests)، U4 (أعراض الازدواج)، U5 (تهيئة التخزين)، U10 (`StatusDashboardRepositoryImpl`) — كلها فحوصات داخلية صغيرة، لا عوائق معمارية.
