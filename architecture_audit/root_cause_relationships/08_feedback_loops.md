## 2. المرشح الوحيد لحلقة سببية: E ↔ G

```
مسار مزود جديد في العرض (E)
  → مواقع تسرب نصي جديدة (17 موقعاً) (G)
    → القناة النصية تصبح المعيار الفعلي
      → لا ضغط لسحب المعالجة لطبقة مُنمَّطة
        → المسار التالي يُبنى في العرض أيضاً (E) ...
```

- **الدعم:** الاتجاهان مثبتان منفصلين (E→G بالتوسع المقاس، G→E بالالتفاف حول `anyErrorUserMessage`).
- **الحكم:** حلقة **مرشحة** بثقة متوسطة — الآلية معقولة والأدلة ظرفية (لا توجد سلسلة زمنية commits تثبت التتابع).
- **ما يدحضها:** إثبات أن التسرب النصي سبق التوسع العرضي زمنياً (يتطلب `git log -S` لكل موقع — خارج نطاق هذه الجولة، ومقترح كتحقق لاحق).

## 3. حلقات مرفوضة صراحةً

| المرشح | الحكم |
|---|---|
| "غموض الملكية → استيرادات عابرة → حالة مشتركة → مزيد غموض" (المثال الافتراضي في التوجيه) | **مرفوض** — الاستيرادات تتبع التموضع لا العكس (EldDrawer استُورد *لأنه* في home؛ لم يجعل home غامضاً أكثر). لا سلسلة تغذية موثقة |
| "لا إنفاذ → انتهاكات → مزيد انتهاكات" | **مرفوض كحلقة** — H خلفية ثابتة لا متغير يتغذى (لا آلية عائدة) |
| "الدورة الكبرى → هشاشة → مزيد استيرادات" | **مرفوض** — لا دليل على نمو الدورة ذاتياً |

## الخلاصة

**صفر حلقات سببية مؤكدة، ومرشح واحد (E↔G).** معظم "الدوائر" في المشروع بنيوية ساكنة. الخطر الحقيقي ليس التغذية الراجعة بل **التراكم الخطي بلا كلفة** (RC-H).
