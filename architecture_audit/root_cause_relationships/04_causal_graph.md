# 04 — الرسم السببي الموجَّه (Causal Graph)

> حواف موجَّهة مدعومة فقط. لا تُحوَّل الارتباطات لأسهم. الثمانية **غير** متصلة كلها — وهذا تقرير بحد ذاته.

## الحواف المؤكدة

```
F ──DIRECT──▶ E        (نكهة التحليل في العرض فقط؛ الدليل: عقود RawJson تُجبر
                        التنقل اليدوي — team_status:26-32 نموذجاً)

E ◀──MUTUAL──▶ G       (كل مسار مزود جديد يضيف مواقع تسرب نصي؛ والقناة النصية
                        المتاحة تُبقي المعالجة في المزودات — 17 موقعاً)
```

## العناقيد ذات السبب المشترك (ليست أسهماً سببية)

```
        ┌─ غياب طبقة التطبيق ─┬─▶ A (تشتت التركيب)
        │                      └─▶ E (التنسيق في العرض)
        │
        └─ غياب اتفاقية مواطن النماذج ─┬─▶ B (عبور النماذج)
                                       └─▶ F (اقتراض DTO عبر الحدود)
```

## الخلفية المُمكِّنة (ليست عقدة سببية)

```
        H ─ ─ ─ (تمكين بالسماح، لا توليد) ─ ─ ─▶ A, B
        [تزامن موثّق بالعلامات؛ CORRELATED_ONLY]
```

## العقد المنعزلة (بلا حواف داخلة/خارجة مؤكدة)

```
C (التوجيه)     D (السياج)      — منعزلان سببياً عن الرسم رغم جسامة أعراضهما
```

## قراءة الرسم

| الموضع | العقد |
|---|---|
| **المنبع الوحيد المولِّد** | F (يولّد نكهة من E) |
| **الحلقة الوحيدة** | E ↔ G (تعزيز متبادل — المرشح الوحيد لحلقة سببية، انظر 08) |
| **الأسباب المشتركة** | غيابان اتفاقيتين يفسّران 4 عقد (A,E,B,F) |
| **المنعزلات** | C, D — مشكلتان حقيقيتان كبيرتان **لا تسببهما** بقية الشبكة ولا تسببانها |
| **الخلفية** | H — تسمح للكل بالبقاء، لا تولّد شيئاً محدداً |

## ما الذي يعنيه العزل؟

- إصلاح C (الدورة) لا يُصلح شيئاً آخر ولا يتطلب إصلاح غيره — **قابل للعزل الكامل**.
- إصلاح D (توحيد السياج) لا يمس E/F/G — **قابل للعزل الكامل**.
- F→E تعني: تنميط العقود **سيُجفف** نكهة التحليل في العرض تلقائياً (دون نقل التنسيق نفسه).
- E↔G تعني: كسر أي من الاتجاهين يُضعف الآخر (نوع مُنمَّط للأخطاء **أو** سحب المعالجة من المزودات).
