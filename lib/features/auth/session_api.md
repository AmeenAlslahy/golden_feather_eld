1. نظرة عامة
توفر هذه المجموعة من نقاط النهاية واجهة لإدارة جلسات المستخدمين في خادم Traccar. يتم إنشاء الجلسة تلقائياً عند تسجيل الدخول عبر TraccarService، ويتم استخدامها للمصادقة على جميع الطلبات اللاحقة. تدعم هذه النقاط الحصول على معلومات الجلسة الحالية وتسجيل الخروج.

2. الفوائد والميزات
إدارة الجلسات المركزية: تتبع الجلسات النشطة للمستخدمين.
أمان متقدم: الجلسات محمية بواسطة Cookies ومهلة زمنية محددة.
تسجيل الخروج الآمن: إنهاء الجلسة وإزالة بيانات المصادقة.
مرونة: إمكانية التحقق من حالة الجلسة قبل تنفيذ العمليات الحساسة.
3.1. الحصول على معلومات الجلسة الحالية
GET /session

الوصف: الحصول على معلومات الجلسة الحالية للمستخدم المسجل دخوله.

معاملات Query
لا توجد معاملات إضافية مطلوبة.

الاستجابة
الحقل	النوع	الوصف
id	integer	معرف الجلسة
userId	integer	معرف المستخدم
createdAt	string	وقت إنشاء الجلسة (ISO 8601)
expiresAt	string	وقت انتهاء الجلسة (ISO 8601)
ipAddress	string	عنوان IP الذي تم إنشاء الجلسة منه
userAgent	string	متصفح/وكيل المستخدم
مثال
الطلب:

GET /api/v1/tracker/traccar/session
Authorization: Bearer <your_access_token>
الاستجابة:

{
    "code": 200,
    "status": true,
    "data": {
        "id": 1,
        "userId": 5,
        "createdAt": "2026-01-15T10:00:00Z",
        "expiresAt": "2026-01-15T22:00:00Z",
        "ipAddress": "192.168.1.100",
        "userAgent": "Mozilla\/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit\/537.36"
    }
}
3.2. تسجيل الخروج
POST /logout

الوصف: تسجيل الخروج من خادم Traccar وإنهاء الجلسة الحالية.

مثال
الطلب:

POST /api/v1/tracker/traccar/logout
Authorization: Bearer <your_access_token>
الاستجابة:

{
    "code": 200,
    "status": true,
    "message": "تم تسجيل الخروج بنجاح"
}
4. آلية المصادقة
تعتمد المصادقة في هذه الـ API على الجلسات التي يديرها TraccarService. عند إنشاء كائن الخدمة، يتم استدعاء دالة login() تلقائياً، والتي ترسل طلب POST إلى /api/session مع بيانات الاعتماد (البريد الإلكتروني وكلمة المرور) المخزنة في الإعدادات. يتم تخزين Cookie الجلسة وإعادة استخدامها في جميع الطلبات اللاحقة.

في حالة انتهاء صلاحية الجلسة، سيعيد الخادم رمز خطأ 401 (غير مصرح)، ويمكن إعادة المصادقة تلقائياً أو يدوياً عبر استدعاء login() مرة أخرى.

4.1. إعدادات الاتصال
يتم تحميل إعدادات Traccar من ملف الإعدادات الخاص بالإضافة (nano3.tracker::traccar) أو من متغيرات البيئة:

المفتاح	الوصف	القيمة الافتراضية
base_url	عنوان خادم Traccar	http://localhost:8082
email	البريد الإلكتروني للمستخدم	admin@example.com
5. التنبيهات والتوصيات
التنبيه	الوصف
انتهاء الجلسة	الجلسات تنتهي تلقائياً بعد فترة زمنية محددة (عادة 12 ساعة). تأكد من التعامل مع حالات انتهاء الصلاحية في التطبيق الخاص بك.
تخزين البيانات الحساسة	لا تقم بتخزين بيانات الاعتماد (البريد الإلكتروني وكلمة المرور) في الكود المصدر. استخدم متغيرات البيئة أو نظام الإعدادات.
إعادة المصادقة	في حالة فشل الطلب برمز 401، حاول إعادة المصادقة عن طريق استدعاء login() قبل إعادة الطلب.
تعدد الجلسات	يمكن للمستخدم أن يكون لديه جلسات متعددة من أجهزة مختلفة. استخدم نقاط نهاية الجلسات النشطة (/sessions) لإدارتها.
